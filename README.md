# Nick Cinera Resume

Public resume artifacts for Nick Cinera in English and Spanish, focused on real-time trading UI, client/server architecture, and capital-markets workflow platforms.

## Files

- `index.html` - static web resume for GitHub Pages at `https://extrieve.github.io/nick-resume/`.
- `es/index.html` - Spanish web resume at `https://extrieve.github.io/nick-resume/es/`.
- `docs/` - self-contained mirror (including downloads) for repositories configured to publish Pages from `/docs`.
- `output/Nick_Cinera_Resume.pdf` - polished one-page resume for applications and recruiter sharing.
- `output/Nick_Cinera_Resume.docx` - editable Word version.
- `output/Nick_Cinera_Resume.md` - source text version.
- `output/Nick_Cinera_Resume_ES.pdf` - Spanish PDF resume.
- `output/Nick_Cinera_Resume_ES.docx` - editable Spanish Word version.
- `output/Nick_Cinera_Resume_ES.md` - Spanish source text version.

## Web Version

The static web resume is published through GitHub Pages:

- Pages URL: `https://extrieve.github.io/nick-resume/`
- Spanish Pages URL: `https://extrieve.github.io/nick-resume/es/`
- GitHub-rendered Markdown fallback: `https://github.com/Extrieve/nick-resume/blob/main/output/Nick_Cinera_Resume.md`

If GitHub Pages needs to be reconfigured, set the publishing source to `main` / root in repository Settings > Pages.

## Positioning

The resume emphasizes production ownership at the client/server boundary of real-time trading platforms at Goldman Sachs, including React/TypeScript, AG Grid, Redux/RxJS, typed Java/WebSocket contracts, server-driven projections, versioned snapshot/delta subscriptions, controlled migrations, testing, rollout, and production support.
